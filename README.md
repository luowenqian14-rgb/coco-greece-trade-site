# COCO 深海商品灵感站

COCO 中国 × 希腊外贸商品展示网站原型。整页共用一张贴近海平面的实拍海浪视频，首屏展示起伏海浪，滚动时同一画面持续铺在下方并逐渐压暗，接入深蓝商品目录，没有两张背景的拼接边。视频 13 秒循环并在接缝处柔和过渡。目录含 8 个虚拟商品概念，可按美甲闪饰、饰品配件、手机周边、美妆个护和家居小物分类筛选。

## 本地预览

直接用浏览器打开 `index.html`。首屏视频为 `assets/ocean-waves-sunrise.mp4`，静态备用画面为视频同源截帧 `assets/ocean-poster.jpg`；商品概念图形由 CSS 绘制。目录过滤、移动端导航和商品咨询邮件草稿可直接使用。邮件地址尚未配置，点击咨询后需自行补充收件人。

海面视频素材：Pexels 摄影师 juv 的 [Water Level Shot With View Of Sunset](https://www.pexels.com/video/water-level-shot-with-view-of-sunset-3138050/)，按 [Pexels License](https://www.pexels.com/license/) 使用并裁切、压缩为网页背景。用户开启系统减少动态效果时，页面使用静态海景图替代自动播放。

## 市场线索

- Skroutz《2025年度消费者与商家报告》指出，手机是平台最热门搜索，其次为运动鞋；2025 年健康美妆销售同比 +22%、家居园艺 +21%、科技 +19%、时尚 +12%。此为平台数据，不能等同希腊全市场，也不保证单个商品销量。
- Nexi 希腊电商调查显示服装是消费者常购的网购品类，美容产品也有明显购买需求。美甲饰品是依据美妆消费趋势与用户选品方向延伸出的商品概念，尚需希腊买家访谈验证。

## 原型边界

商品卡片是用于展示分类和视觉风格的虚拟商品，不代表现货、品牌授权、价格或 COCO 已有供货。正式上架前要验证希腊买家需求、供应商、样品品质、进口成本、标签和产品合规。
